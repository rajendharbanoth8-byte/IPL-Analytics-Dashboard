#  IPL Analysis Dashboard (2008–2025) | Power BI Project

## Overview

This project presents an interactive analysis of **IPL data from 2008 to 2025** using Power BI.

It transforms raw match-level and ball-by-ball data into meaningful insights related to **team performance, player statistics, and season trends**.

The objective is to analyze **championship outcomes, player impact, and league performance patterns** using an interactive dashboard.

---

## Dataset

### Data Sources

* Match-level dataset
* Ball-by-ball dataset
* Player dataset
* Team dataset

### Data Scope

* Seasons: 2008–2025
* Teams, players, and match performance data
* Points table and tournament statistics

## Project Workflow

### 1. Data Collection

* Imported IPL datasets (matches, players, ball-by-ball data)
* Cleaned and structured data for analysis

### 2. Data Modeling

* Created relationships between:

  * Matches ↔ Teams
  * Matches ↔ Ball-by-ball data
  * Players ↔ Performance metrics

### 3. Data Preparation

* Cleaned and transformed datasets
* Created calculated fields for KPIs
* Ensured consistency across seasons

### 4. Dashboard Development (Power BI)

* Built interactive visuals for IPL analysis
* Implemented season-based filtering (2008–2025)
* Designed KPIs and performance cards using DAX

### 5. Report & Presentation

* Created detailed analytical report summarizing insights
* Built presentation using Gamma AI for business storytelling

---

## Dashboard Features

* Season slicer (2008–2025) for dynamic analysis

* Automatic identification of **Champion & Runner-up teams**

* Key KPIs:

  * Total Matches
  * Total Teams
  * Total Fours & Sixes
  * Centuries & Half-Centuries
  * Total Venues

* Player Performance Insights:

  * Orange Cap (Top Run Scorer)
  * Purple Cap (Top Wicket Taker)
  * Most Fours & Sixes

* Points Table:

  * Matches Played
  * Wins & Losses
  * No Result
  * Total Points

---

## Key Results

* Aggressive batting trend observed with increasing boundaries (4s & 6s)
* League shows high competition with minimal point differences among top teams
* Team balance is more important than individual performance for winning titles
* Top teams consistently dominate majority of wins
* Player excellence does not always guarantee championship success

---

## Key Insights

* Modern IPL favors high-scoring, aggressive gameplay
* Consistency in league stage is critical for qualification
* Balanced team performance outperforms individual brilliance
* Competition intensity has increased across seasons
* Data-driven decision-making can improve team strategy and auction planning

## How to Run

### 1. Open Power BI File

* Load the `.pbix` file in Power BI Desktop

### 2. Load Dataset

* Ensure all datasets (matches, players, ball-by-ball) are connected correctly

### 3. Refresh Data

* Click **Refresh** to update visuals and KPIs

### 4. Explore Dashboard

* Use season slicer (2008–2025)
* Interact with KPIs, charts, and points table
